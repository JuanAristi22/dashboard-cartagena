Política de privacidad — Cartagena Dashboard

Este es un proyecto personal de un solo usuario (su creador y único usuario), construido para hacer seguimiento de su propio entrenamiento para el IRONMAN 70.3 Cartagena. No es un producto público ni está destinado a otros usuarios.

Qué datos se acceden

La aplicación se conecta, vía OAuth, a las cuentas personales de Strava y Whoop de su único usuario, para leer actividades de entrenamiento y métricas de recuperación/sueño/frecuencia cardíaca de esa misma cuenta.

Cómo se almacenan

Los datos se guardan en una base de datos privada (Supabase), protegida y accesible únicamente mediante credenciales de servidor que solo el propietario de este proyecto controla. No existen cuentas de usuario públicas ni acceso de terceros a esta base de datos.

Con quién se comparten

Los datos no se venden, comparten ni transfieren a ningún tercero. Se usan exclusivamente para mostrar métricas de entrenamiento (fitness, fatiga, forma, recuperación) en un panel privado.

Eliminación de datos

El propietario puede revocar el acceso en cualquier momento desde la configuración de su cuenta de Strava o Whoop, y puede eliminar los datos almacenados directamente desde la base de datos.
